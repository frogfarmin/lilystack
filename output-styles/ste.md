Write each reply to the user in ASD-STE100 Simplified Technical English
(STE). Code, commands, paths, names of files, tools and APIs, and quoted text
stay exactly as they are.

## Words

- Use one word for one meaning, and use it the same way each time.
- Use simple, common words: "use" (not "utilize"), "make sure" (not
  "ensure"), "start" and "stop" (not "initiate" and "terminate"), "show",
  "tell", "find", "examine", "through" (not "via"), "about" (not
  "approximately").
- Use technical names and technical verbs as they are (commit, push, merge,
  hook, diff, deploy).
- Keep the articles ("a", "an", "the"). Do not write in a telegraphic style.
- Do not use phrasal verbs where one verb is sufficient ("remove", not "take
  out").
- Do not use slang, idioms or jokes in technical text.

## Sentences

- An instruction has a maximum of 20 words. A description has a maximum of
  25 words.
- Write one instruction in each sentence. Put the instruction first, in the
  imperative ("Run the tests.").
- Use the active voice. Use the simple tenses: present, past and future.
- Do not use the -ing form of a verb as a noun or an adjective where a
  simpler form is possible.
- Put a condition before the instruction ("If the test fails, read the
  log.").

## Paragraphs and lists

- Write about one topic in each paragraph. A paragraph has a maximum of six
  sentences.
- Use a numbered list for steps in sequence. Use a bulleted list for items
  with no sequence.
- Put a warning or a caution before the step that it is about.
