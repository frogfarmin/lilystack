# lilystack secrets rules. One per line: tier<TAB>scope<TAB>name<TAB>reason<TAB>regex[<TAB>unless-regex].
# Tiers: deny (blocked) or ask (a prompt). Each regex is POSIX ERE, matched case-insensitively (grep -E -i).
# The first matching row wins, so deny rows come first. A match on unless-regex turns that row off for
# the same subject. Scopes, and what each regex is matched against:
#   path   every path the tool names (Read, Edit, Write, MultiEdit file_path; NotebookEdit notebook_path;
#          Grep path), three ways: as given, made absolute against the payload cwd, and symlink-resolved
#   write  the same paths, for Edit, Write, MultiEdit and NotebookEdit only
#   bash   the Bash command, line by line
#   text   the text being written (Write content, Edit and MultiEdit new_string, NotebookEdit new_source)
#          and the Bash command
# Edit a line to change a rule; tests/test-hooks.zsh pins the behaviour.
#
# deny
